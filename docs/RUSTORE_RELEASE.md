# FinOS: публикация в RuStore

Актуально на 28 сентября 2026 года.

## Параметры приложения

- Название: `FinOS`
- Категория: `Финансы`
- Production URL: `https://fin-os-ashen.vercel.app`
- Web manifest: `https://fin-os-ashen.vercel.app/manifest.webmanifest`
- Android package: `app.finos.mobile`
- Версия первого релиза: `1.0.0` (`versionCode 2`)
- Ориентация: портретная
- Цвет темы и заставки: `#f7f1ea`
- Формат первого релиза: подписанный APK
- SHA-256 сертификата: `18:89:67:EC:CE:19:C8:DD:6C:41:58:C0:20:E2:BA:30:79:E4:EC:3D:D7:77:E7:0B:A0:5D:D4:97:EE:10:13:6C`

Package name и ключ подписи нельзя менять после публикации без процедуры миграции. Файл ключа и пароль необходимо хранить в двух защищённых местах вне Git.

## Что подготовлено в веб-приложении

- PWA manifest и иконки 192/512 px.
- Экран запуска в фирменных цветах.
- Service Worker с кэшем оболочки и понятным экраном при отсутствии сети.
- Локальное хранение финансовых данных и JSON-резервная копия.
- Мобильная навигация, микрофон и экспорт файлов.

## Сборка Android

Проект создаётся через официальный Bubblewrap из production-манифеста. Результат сборки:

- `app-release-signed.apk` — файл первого релиза для RuStore;
- `app-release-bundle.aab` — запасной вариант, если позже понадобится AAB.

SHA-256 ключа опубликован для Digital Asset Links в:

`public/.well-known/assetlinks.json`

Этот файл необходимо развернуть вместе с веб-приложением. Без Digital Asset Links приложение откроется как вкладка браузера с адресной строкой.

Локальные секреты сборки находятся в `.secrets/finos-rustore/` и исключены из Git. До публикации скопируйте ключ и пароль в два независимых защищённых места.

## Карточка RuStore

Тексты карточки находятся в `rustore/listing-ru.md`.

До отправки на модерацию нужны:

1. Аккаунт разработчика RuStore.
2. Данные оператора и контакт поддержки для публичной политики конфиденциальности.
3. От 3 до 5 чистых скриншотов без интерфейса браузера.
4. Подписанный APK и сохранённый ключ подписи.
5. Заполненный раздел «Безопасность данных».
6. Проверка установки APK на физическом Android-устройстве.

## Безопасность данных

В декларации необходимо указать фактическую обработку:

- Telegram ID, имя и username при авторизации через Telegram;
- финансовые записи пользователя;
- голос и расшифрованный текст при использовании голосового ввода;
- технические данные запросов и устройства;
- сведения о подписке и платежах;
- передачу данных инфраструктурным поставщикам, указанным в политике конфиденциальности.

Функции, требующие сеть: синхронизация, ИИ-советник, распознавание голоса, авторизация и оплата. Локальные записи, уже загруженная оболочка и JSON-резервные копии остаются доступны на устройстве.

## Монетизация

Первую версию лучше публиковать как бесплатное приложение. До включения платной подписки в Android-релизе необходимо отдельно проверить требования RuStore и выбрать единый сценарий покупки. Для встроенных цифровых подписок RuStore предоставляет Pay SDK.

## Финальная проверка

- запуск без браузерной панели;
- возврат системной кнопкой «Назад»;
- добавление и редактирование операции;
- прогноз, цели, долги и регулярные платежи;
- голосовой ввод с запросом разрешения на микрофон;
- сохранение и восстановление JSON-файла;
- вход и синхронизация после перезапуска;
- экран без сети;
- переходы к политике конфиденциальности и поддержке;
- отсутствие битых ссылок и старого бренда VoiceBudget.
